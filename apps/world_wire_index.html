How the wire works

The page attempts each publisher feed directly when browser CORS permits it, then optionally uses a self-hosted gateway, then public compatibility fallbacks. The health panel tells you which path succeeded. For stronger sovereignty, point CONFIG.gatewayURL at your own raw CORS gateway and disable the public fallbacks.
