# Verifier layout, navigation, and news application audit

## Repairs

- Homepage name: responsive 48–96 px; eyebrow: 14 px. Other pages retain their existing typography standard.
- Application and network cards use equal grid tracks, equal row heights within each grid, and responsive 4/3/2/1 columns. Column and principle grids also use equal rows.
- Fixed the Live Research home link, replaced the unavailable Academy domain with the working Academy portal, and routed the unavailable Veterans landing page to the existing national Veterans Resource Hub.
- Connected Live News, Research & Primary Source Feed, World Wire, and Education News to the same-origin published edition; removed browser RSS proxy chains from those applications. Preserve local-cache fallback and original publisher links.
- Added 13 specialist publisher feeds to the canonical registry. Corrected stale ALA, Education Week, Inside Higher Ed, and Nature feed addresses. Increased the edition cap to accommodate specialist feeds.
- Vintage News and Vintage News Digest now read actual published headlines rather than creating simulated articles. Existing local archives are retained; a notice identifies possible legacy sample entries. Local news search now opens real search resources. The file-details control accurately states that it stores metadata only.
- EcoPulse refresh clears its in-memory edition request. Daily edition freshness follows a 30-hour window instead of declaring a daily publication stale after three hours.
- Cache version advanced and typography/home extension included in the offline shell. Source-registry changes automatically trigger a news build.
- Updated the Ultimate News card to describe its functioning newsroom gateway rather than an unfinished flagship.

## Verification

- All steps of the repository's integrity-audit workflow passed locally: architecture, navigation, feed URL security, client regression tests, Python syntax, JavaScript assets, and inline scripts.
- 164 static local references in 42 HTML pages passed. Static fragment targets and homepage application file references passed.
- Homepage and all 22 app pages initialized in an isolated DOM runtime without application errors. External requests were deliberately unavailable there; that run checks code execution and fallback behavior, not publisher availability. The portfolio iframe was not a full browser test.
- Exercised search inputs and selected controls across the homepage, Modern News Engine, Daily Top 30, Live News, World Wire, both vintage apps, and EcoPulse; no runtime errors. This is not exhaustive every-state testing.
- Checked 29 static/network external destinations. The two failing destinations were repaired using existing ecosystem resources. Other dynamically generated publisher/article destinations were not all exhaustively requested.
- Retrieved all 13 added feed URLs directly for inspection; Nature uses RSS 1.0/RDF, supported by the existing namespace-independent parser.
- Added four dependency-free client regression tests: daily freshness, shared source requests/reset and unsafe-link rejection, genuine vintage story mapping/selection, and offline error propagation.

## Limits and preserved behavior

- Full browser visual/mobile, print/download, notifications, and IndexedDB verification remains outstanding: the browser binary download failed in this environment. DOM tests do not measure rendered geometry.
- Publisher outages, paywalls, remote images, and NASA's public API may vary independently of the application. An unavailable source is reported rather than replaced with fabricated news.
- The local server-side feed build could not resolve public DNS under this environment's network policy. Its temporary empty output was discarded; the previous generated edition was preserved. The GitHub Actions build must publish the expanded edition before the new specialist sources appear.
- No STOS files or runtime artifacts were modified. No third-party runtime dependencies were added to the website.
